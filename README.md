# SIGEVI - Sistema de Gestión de Inventario

Proyecto de práctica para la evidencia GA7-220501096-AA1-EV05.

Este repositorio tiene como objetivo demostrar el uso de Git
para el control de versiones de un proyecto de software.

## Objetivo

Implementar un ejemplo básico de control de versiones utilizando
un repositorio local y un repositorio remoto.

## Tecnologías

- Git
- GitHub
- HTML
- CSS
